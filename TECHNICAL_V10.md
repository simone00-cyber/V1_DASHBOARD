# Technical Analysis Lab v10.0

This release refactors the direct technical-analysis workspace.

## Chart workspace

- Compact synchronized price, volume and RSI panels.
- Robust volume scaling based on the visible window so isolated outliers do not flatten the histogram.
- Green/red volume bars based on candle direction.
- Shared pan, zoom, hover and bottom range slider.
- Support and resistance displayed only as highlighted zones.
- Nearest zones receive stronger visual emphasis.

## Technical summary

- Current technical state.
- Nearest support and resistance.
- One latest dated event.
- Deterministic technical story generated from calculated indicators.
- Four recent events and an expandable full history.

The Technical Analysis Lab remains descriptive and does not generate BUY or SELL recommendations.
