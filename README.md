# Cyclical Global Macro Terminal — Modular

## Avvio

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Struttura

- `app.py`: avvio e navigazione
- `config/`: tema e universi ticker
- `data/`: download Yahoo Finance
- `core/`: trasformazioni e metriche generali
- `analysis/`: logica macro, regime, shipping e security report
- `charts/`: grafici Plotly
- `ui/`: componenti riutilizzabili
- `pages/`: una pagina Streamlit per file
- `caruso_analysis.py`: motore Composite Momentum documentale

La sezione shipping usa ancora dati simulati, come nel file originale.

## Fase 2 — Security Report professionale

La pagina Security Report ora distingue tra:

- **posizione tattica attiva** (`LONG`, `SHORT`, `NEUTRALE`);
- **evento dell'ultima barra settimanale**;
- data di generazione ed età del segnale;
- fase settimanale corrente;
- condizioni necessarie per un nuovo BUY o SELL SHORT;
- condizione di invalidazione o rivalutazione;
- storico degli ultimi eventi prodotti dalla matrice multi-timeframe.

Esempio importante: con trimestrale `UP`, mensile `UP` e settimanale
`PROSEGUE DOWN`, il terminale non mostra un BUY. Identifica una correzione
settimanale dentro un quadro rialzista e richiede una nuova `SVOLTA UP`
settimanale come trigger, purché trimestrale e mensile rimangano `UP`.

Il motore ricostruisce lo storico usando esclusivamente la matrice documentale
presente nel progetto; non aggiunge indicatori tecnici esterni.

L'Investitore Disciplinato resta volutamente **non implementato**, perché la
formula proprietaria dei livelli Long/Neutral/Short non è contenuta nei
materiali disponibili.

## Cyclical Engine v2 - Strategy Lab

The `STRATEGY LAB` page reconstructs the historical events generated by the
public quarterly/monthly/weekly tactical matrix and tests two explicitly
labelled execution conventions:

- `LONG_ONLY`: BUY opens a long position; SELL SHORT or TAKE PROFIT closes it.
- `LONG_SHORT`: BUY and SELL SHORT reverse direction; TAKE PROFIT moves to cash.

Signals are generated on completed weekly bars. A position decided at a weekly
close affects returns from the following bar, preventing look-ahead. Costs are
configurable in basis points per execution.

The module does **not** implement Investitore Disciplinato, proprietary stops,
undisclosed trigger prices, sizing, leverage or pyramiding.

## Research Lab v1 (Cyclical Engine v3)

## Strategy Lab — Drawdown Analysis

The existing Research section now includes a `DRAWDOWNS` tab. It adds:

- peak-to-trough drawdown episode detection;
- top drawdown ranking with start, trough, recovery and duration;
- trade drill-down for each drawdown interval;
- gross loss attribution by setup, monthly direction, entry rating and
  Composite Momentum zone;
- explicit separation between descriptive attribution and signal generation.

The analysis does not alter the public formulas, matrix instructions or
execution policy. It explains where historical risk was concentrated under the
selected research policy.


## Price-series convention (v8.4)

- Signal engine, KEY, XTL, Composite Momentum, cycles and Active Position use adjusted OHLC values derived from Yahoo Adjusted Close.
- Performance analytics also use the adjusted total-return series.
- Candlestick charts, last price and displayed entry/exit prices use actual traded OHLC values.
- This is a transparent framework convention; the public methodology documents do not specify the adjustment convention.

## Maritime Intelligence (AISStream)

The former simulated Shipping page has been replaced by a live AIS dashboard for the Strait of Hormuz. It uses a backend WebSocket connection to AISStream and displays vessel positions, broad AIS vessel class, MMSI/IMO when transmitted, speed, course, indicative inbound/outbound direction, destination, ETA and draught when available.

Setup:

```bash
cp .env.example .env
# edit .env and set AISSTREAM_API_KEY
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The API key is never embedded in source code. AISStream is a beta/community feed: coverage and field completeness may vary, and exact cargo, ownership and operator are not inferred.
