# Global Macro v10.6 — Interactive Series Controls

## Changes

- Removed the European 10Y sovereign-yield histogram from the rates section.
- Added user-selectable US Treasury maturities for both the current curve and historical chart.
- Added user-selectable ECB euro-area AAA maturities for both the current curve and historical chart.
- Added visibility controls for sovereign bond price proxies.
- Added visibility controls to FX, commodities, crypto and credit charts.
- Tables now follow the same selected instruments shown in the corresponding chart.
- Empty selections are handled with a clear information message instead of an empty Plotly chart.

The controls change chart visibility only. They do not alter source data, calculations or macro commentary.
